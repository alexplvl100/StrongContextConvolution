# Rollout: DeepSeek Harness (DSH)

**Статус:** заготовка. Описание подключения будет добавлено отдельной задачей.

Первый rollout — DSH. Выбор не случаен: ядро SCC развивалось именно на журналах
DSH, и формат этих журналов (`session.v4.jsonl.zstd`) уже понимает конвертер
`_engine/core/scc_events.py`. То есть первая точка подключения — чтение контекста — для
DSH **уже работает**, а не требует отдельной разработки.

Что предстоит решить при описании подключения: где именно в DSH ставить триггер
свёртки (в харнессе есть собственный механизм компакции, и SCC должен либо
заменить его, либо работать рядом), как передавать агенту инструкцию архива и
как организовать доступ к архивным чанкам через Архивариуса.

Заготовка раздела — в `ROLLOUT.md`; он скопирован из шаблона и заполнен частично.
